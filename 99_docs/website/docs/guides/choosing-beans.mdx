This page shows how a bean asks for one of several beans of the same type. Use it when two or more beans implement one trait, such as two payment gateways.

## Mark the default bean with @Primary

When several beans match a parameter, the bean marked `@Primary` is injected:

<CodeBlock language="scala" title="CardGateway.scala">{CardGateway}</CodeBlock>

<CodeBlock language="scala" title="TransferGateway.scala">{TransferGateway}</CodeBlock>

Without `@Primary`, a parameter that matches several beans stops the startup with `AmbiguousBeanException`, which lists the matching beans.

## Ask for a bean by name with @Qualifier

Annotate a parameter with `@Qualifier` to get the bean with that name, whether it is primary or not. A bean is named after its class, starting with a lower-case letter, or after its `@Bean` method:

<CodeBlock language="scala" title="Checkout.scala">{Checkout}</CodeBlock>

The bean with the name must exist and have the type of the parameter, otherwise the startup stops with `NoSuchBeanException`. `@Qualifier` selects one bean, so it is not allowed on `Option[T]` or `List[T]` parameters.

## Take every bean, or none

A `List[T]` parameter gets every bean of type `T`, possibly none, and an `Option[T]` parameter gets the chosen bean when there is one. In the example, `allGateways` contains both gateways.
