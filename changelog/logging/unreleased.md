### Added

- The MDC of `coilix-logging` belongs to the fiber in code that runs in `IO`: it stays across thread changes and is copied to the fibers it starts. Outside a fiber it belongs to the thread. `CoilixIOApp` sets `cats.effect.trackFiberContext=true`, which tests outside it set in `Test / javaOptions` (COILIX-00031).
- `LoggingSettings.read` returns the settings or a `ConfigError` for an unknown level, so they can be read without exceptions; `LoggingSettings.from` throws it as `ConfigurationException` (COILIX-00031).
- New module `coilix-logging`, the SLF4J 2 provider of the application, with the bridges `jul-to-slf4j`, `log4j-to-slf4j` and `jcl-over-slf4j`, so the application and every library log in one format: time, level, thread, shortened logger name, message, MDC and stack trace, with colored levels unless `coilix.logging.colors` is false and on a background thread with `coilix.logging.async`. `coilix.logging.level` sets the root level and `coilix.logging.levels` the levels of packages and classes, the longest matching name winning and `off` silencing them. The `logLevels` bean (`LogLevels`) reads and changes the levels in `IO` while the application runs (COILIX-00033).
